Upload Data

Each upload replaces the previous data of the same file completely.

1. Employees file

Columns: Code, Name, Title, Department, Location, Type (FTE / Outsource), Manager 1 Code, Manager 2 Code (optional). Each employee is shown to manager 1 and manager 2 under Actual Manpower.

Download the template ·

2. Titles file

Columns: Title, Department. All managers see every title under its department in Request Manpower. Titles in the employees file are added automatically, so use this file for titles that have no employees yet. Locations come from the employees file.

Download the template ·

3. Managers file (accounts)

Columns: Code, Name, National ID. Only the managers in this file get an account. They sign in with their code, and their password is the last 4 digits of their National ID (they can change it later). The National ID itself is not saved. Manager accounts that are not in the file are removed. HR and OD BU accounts are not affected.
